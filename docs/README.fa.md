# mh-bookmark-organizer — راهنمای فارسی

ابزاری برای مرتب‌کردن بوکمارک‌های مرورگر: حذف تکراری‌ها، پیدا کردن لینک‌های مرده، چیدن بوکمارک‌های بدون پوشه در پوشه‌های مناسب (بر اساس پوشه‌هایی که خودتان ساخته‌اید)،
بازسازی درخت پوشه‌ها، برچسب‌گذاری و جست‌وجوی کامل‌متن. یک موتور محلی پایتون (`mhbm`) است با خط فرمان، سرور MCP، افزونه برای Claude Code و OpenAI Codex، افزونهٔ Chromium و
یک صفحهٔ وب محلی. فقط به کتابخانهٔ استاندارد پایتون و پایتون ۳٫۹ یا بالاتر نیاز دارد و بوکمارک‌های شما روی دستگاه خودتان می‌ماند.

نسخهٔ کامل و دقیق‌تر (انگلیسی): [README.md](../README.md)

## نصب

پایتون ۳٫۹ یا بالاتر باید با نام `python3` در دسترس باشد (در ویندوز `py -3`).

**Claude Code**

```
/plugin marketplace add mhnadali/mh-bookmark-organizer
/plugin install mh-bookmark-organizer@mhnadali-skills
```

هنگام فعال‌سازی چهار چیز پرسیده می‌شود: دستور پایتون، **پوشهٔ کتابخانه** (بیرون از افزونه است، پس به‌روزرسانی یا حذف افزونه به آن دست نمی‌زند)، فقط‌خواندنی بودن سرور MCP، و پنهان کردن ابزارهایی که به سایت‌ها وصل می‌شوند.

**OpenAI Codex**

```
codex plugin marketplace add mhnadali/mh-bookmark-organizer
codex plugin add mh-bookmark-organizer@mhnadali-skills
```

کتابخانه در `~/.mh-bookmark-organizer` است و ابزارها فقط در پوشه‌های `Downloads`، `Documents` و `Desktop` (هر کدام که وجود داشته باشد) فایل می‌خوانند و می‌نویسند، هرگز در خود کتابخانه.
فایل خروجی مرورگر را در یکی از آن پوشه‌ها بگذارید و فقط نام فایل را بدهید. برای انتخاب پوشه‌های دلخواه، سرور را دستی ثبت کنید:

```bash
codex mcp add bookmarks --env MHBM_HOME=~/bm-library --env MHBM_MCP_ALLOW_DIRS=~/Downloads:~/exports \
  -- python3 /path/to/mh-bookmark-organizer/.claude/skills/mh-bookmark-organizer/scripts/codex_mcp.py
```

**فقط خط فرمان**

```bash
cd mh-bookmark-organizer/.claude/skills/mh-bookmark-organizer
pip install .          # دستورهای mhbm و mhbm-mcp؛ یا بدون نصب: python3 -m mhbm از پوشهٔ scripts
mhbm doctor            # بررسی نصب و راهنمای رفع مشکل
```

نصب از PyPI (`pip install mh-bookmark-organizer`) آماده شده ولی هنوز منتشر نشده است.

## اولین استفاده

ابتدا بوکمارک‌ها را از مرورگر خروجی بگیرید (در Chrome: *Bookmark manager ← ⋮ ← Export bookmarks*)، سپس در Claude Code یا Codex بگویید:

> use mh-bookmark-organizer to clean up ~/Downloads/bookmarks.html

دستیار فایل را وارد می‌کند، گزارش سلامت می‌دهد (چند تا بدون پوشه، تکراری یا مرده‌اند) و هر بار یک اصلاح را پیشنهاد می‌کند. همین مراحل با دست:

```bash
export MHBM_HOME=~/bm-library
mhbm import ~/Downloads/bookmarks.html      # یا: mhbm import-browser chrome
mhbm stats                                  # گزارش سلامت
mhbm dedupe                                 # پیش‌نمایش؛ با --apply اعمال می‌شود
mhbm learn                                  # پوشه‌های شما چقدر قابل یادگیری‌اند؟
mhbm organize --plan-out plan.json          # پیشنهاد؛ بعد از بازبینی: mhbm apply-plan plan.json --apply
mhbm restructure                            # پیش‌نمایش تغییر درخت پوشه‌ها
mhbm export --format html --out ~/organized.html   # این فایل را در مرورگر وارد کنید
```

`mhbm wizard` همین مراحل را قدم‌به‌قدم و با پرسش پیش از هر تغییر انجام می‌دهد.

## هیچ تغییری بدون دیدن اعمال نمی‌شود

۱. گزارش‌ها و جست‌وجو چیزی را تغییر نمی‌دهند. ۲. هر تغییر گروهی ابتدا فقط **پیشنهاد** (dry run یا «plan») است و شناسهٔ `plan_id` و نمونه برمی‌گرداند. ۳. شما بازبینی می‌کنید
(`mhbm review plan.json` یک صفحهٔ آفلاین برای تیک زدن موردها می‌سازد). ۴. فقط همان plan، یک‌بار و یکجا اعمال می‌شود و فقط اگر کتابخانه از زمان ساخت plan تغییر نکرده باشد؛ پیش از آن نسخهٔ پشتیبان و ردیف undo نوشته می‌شود.
۵. هر زمان `mhbm undo` یا `bm_undo` آن را برمی‌گرداند.

تصمیم‌های سلیقه‌ای با شماست: تکراری‌های «مشابه» (fuzzy) هرگز خودکار ادغام نمی‌شوند؛ لینک فقط پس از چند شکست در طول زمان «مرده» حساب می‌شود (سایت‌هایی که ربات را رد می‌کنند `restricted` هستند، نه مرده)؛
پیشنهادی که رد کرده‌اید دوباره پیشنهاد نمی‌شود.

## دقت چیدن بوکمارک‌ها

`mhbm learn` روی **کتابخانهٔ خودتان** می‌سنجد که چیدن خودکار چقدر دقیق است (جلسه‌های ذخیره‌سازی را کامل کنار می‌گذارد تا بوکمارک با همسایه‌های هم‌زمانش قضاوت نشود). اعداد زیر فقط از **یک کتابخانه** — کتابخانهٔ نویسنده با ۱٬۴۲۲ بوکمارک چیده‌شده در ۱۷۱ پوشه، تا ۱۰ سطح عمق و یک‌چهارم عنوان‌ها فارسی — است و برای شما فرق خواهد کرد:

- پوشهٔ دقیق در ۳۹٪ موارد پیشنهاد اول و در ۵۳٪ موارد جزو سه پیشنهاد اول است.
- با آستانهٔ پیش‌فرض (فقط وقتی ۸۵٪ مطمئن است) تقریباً از هر پنج بوکمارک یکی خودکار چیده می‌شود و حدود نه از ده مورد آن درست است؛ بقیه به دستیار، به `triage` یا به خودتان می‌رسد.
- ۱۸٪ بوکمارک‌های آن کتابخانه در پوشه‌ای بودند که از جلسهٔ دیگری هیچ نمونه‌ای نداشت؛ هیچ مدل یادگیرنده‌ای این بخش را نمی‌تواند حل کند.
- آموزش قطعی (deterministic) است و برای کتابخانهٔ معمولی ثانیه‌ها تا حدود یک دقیقه طول می‌کشد و تا تغییر بوکمارک‌های چیده‌شده ذخیره می‌ماند.

آزمون‌های خود مخزن از کتابخانهٔ مصنوعی استفاده می‌کنند و امتیازشان بسیار بالاتر از واقعیت است؛ فقط برای جلوگیری از پسرفت‌اند، نه ادعای دقت.

## ایمنی و حریم خصوصی

- داده‌ها محلی است؛ شبکه فقط برای بررسی لینک و بایگانی صفحه و فقط به نشانی‌های عمومی (با دفاع در برابر SSRF و DNS-rebinding). جست‌وجوی Wayback فقط با درخواست صریح است و نشانی را به archive.org می‌دهد.
- پروفایل مرورگر در حالت عادی هرگز نوشته نمی‌شود؛ نوشتن (`install-chrome`، `sync`) فقط با مرورگر کاملاً بسته و `--confirm-chrome-closed` و با پشتیبان انجام می‌شود.
- عنوان، یادداشت و متن صفحه‌های بایگانی‌شده «داده‌اند، نه دستور».
- سرور MCP به یک پوشهٔ کتابخانه قفل است، فقط در پوشه‌های مجاز فایل می‌خواند/می‌نویسد، فایل موجود را بازنویسی نمی‌کند، و با `--read-only` هیچ چیز روی دیسک تغییر نمی‌کند.
- پوشهٔ کتابخانه را فقط برای خودتان قابل‌خواندن نگه دارید (`chmod 700`)؛ بوکمارک‌ها تاریخچهٔ مرور شما هستند.

## چه چیزی تأیید شده و چه چیزی نه

**تأیید شده:** مجموعهٔ آزمون (حدود ۶۸۰ آزمون) روی لینوکس؛ یک خروجی واقعی Chrome با ۱٬۵۰۰ بوکمارک (ورود، حذف تکراری، چیدن، بازسازی، undo، خروجی HTML)؛ فایل `Bookmarks` ای که می‌نویسیم در برابر Chromium ۱۴۱ واقعی؛
Firefox ۱۵۷ و Zen و Floorp (Gecko واقعی، بدون رابط)؛ افزونه و native host در Chromium؛ افزونهٔ Claude Code با `claude plugin validate --strict`؛ افزونهٔ Codex در Codex واقعی (نسخهٔ CLI ‏0.163.0: نصب، اجرای سرور، ۲۹ ابزار و یک فراخوانی ابزار).

**تأیید نشده — با احتیاط و با نگه‌داشتن پشتیبان‌ها:** بررسی لینک و بایگانی روی سایت‌های واقعی زیاد؛ macOS و ویندوز (CI برایشان تنظیم شده ولی اجرای آن را ندیده‌ام)؛ پروفایل واقعی Brave/Edge/Vivaldi/Safari؛ نوشتن فایل بوکمارک در پروفایل واقعی Chrome با Sync؛ یک نشست Codex با مدل (نیاز به ورود به Codex دارد)؛ بازبینی حرفه‌ای ترجمه‌های فارسی و عربی و ...
